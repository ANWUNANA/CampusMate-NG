CampusMate NG backend setup

1. Create a Supabase project.
2. Open SQL Editor.
3. Paste schema.sql and Run.
4. Confirm the tables under Table Editor.
5. Use Supabase Auth for student registration/login.
6. The frontend should use only the public/anon key.
7. Never expose the service_role key.
